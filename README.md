# 🪔 Shubh Deepavali – Ram Mandir

An interactive 3D Diwali celebration website featuring a beautifully illuminated Ram Mandir, festive decorations, background music, fireworks, lanterns, and Diwali wishes.

**Created by Ritesh Kumar Singh**

## 🌟 Project Overview

Shubh Deepavali – Ram Mandir is a festive web experience created to celebrate the spirit of Diwali. Explore a virtual temple environment, enjoy festive animations, and experience the celebration with music and interactive controls.

## ✨ Features

- 🛕 Interactive 3D Ram Mandir environment
- 🪔 Beautiful Diwali lighting and decorations
- 🎆 Interactive fireworks
- 🏮 Decorative lanterns
- 🎵 Built-in background Diwali music
- 🔊 Music and sound controls
- 💖 Diwali wishes
- 🔄 Rotate and explore the scene
- 📱 Interactive experience with touch and mouse controls
- 🌌 Night sky and festive visual effects

## 🎮 How to Use

1. Open the website in a modern web browser.
2. Click **Enter with music** to start the celebration with background music.
3. Use the available controls:
   - **Fireworks** – Enjoy fireworks effects.
   - **Lanterns** – Explore lantern effects.
   - **Wishes** – View festive wishes.
   - **Pause Music** – Pause or resume background music.
   - **Sound Off** – Control sound effects.
   - **Temple View** – Explore the temple view.
   - **Rotate** – Change the viewing angle.
4. Drag to rotate the scene and pinch to zoom on supported touch devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Interactive 3D web graphics
- Embedded audio

## 🚀 Run Locally

No complex installation is required.

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `Shubh_Deepavali_Ram_Mandir_Temple_Clear.html`.
4. Open it in Chrome, Edge, or another modern browser.

## 🎵 Music Note

The background audio is embedded in the HTML file, so a separate music file is not required.

**Note:** Some browsers block automatic audio playback. If music does not start automatically, click **Enter with music**.
